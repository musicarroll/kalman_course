\begin{frame}
OP'NAV'DATA'SYNCHING
\begin{verbatim}
     FUNCTION:  The OPNSYNC subfunction performs the nav data synching by
     extrapolating Kalman-corrected INS navigation data to the observation
     time.  This unit performs the extrapolation of INS altitude, velocity, 
     direction cosines, attitude, and the body-to-INS platform transformation 
     matrix (B-matrix).


\end{verbatim}
\end{frame}
