\begin{frame}
KF'EXTRAP'ERROR'STATE'VECTOR
\begin{verbatim}
     FUNCTION:
             THIS FUNCTION EXTRAPOLATES THE ERROR STATE VECTOR FROM
             THE PREVIOUS OBSERVATION TO THE CURRENT TIME. THIS
             EXTRAPOLATION  IS PERFORMED USING A TRANSITION MATRIX
             GENERTATED WITH ONLY THE PT DATA. THE EQUATION INPLEMENTED
             IS

                XV(T') = FVV(T',TP) XV(TP) + FVN(T',TP) XN(TP)
                XN(T') = XN(T)

             WHERE TP IS THE PRECIOUS OBSERVATION TIME AND T' THE
             TIME OF THE STATR OF THE KALMAN CYCLE. THE EXTRAPOLATED
             STATE VECTOR IS USED TO UPDATE THE APPROPRIATE SYSTEM
             VARIABLES. THIS EXTRAPOLATED STATE VECTOR IS A LOCAL
             QUANTITY; IT SHALL BE USED ONLY TO UPDATE SYSTEM
             VARIABLES.

             THE DATA PASSED TO TRANS IS THE SAME PT DATA USED IN THE
             KALMAN EXECUTIVE CALL TO TRANS BUT WITH ZERO DATA IN PLACE
             OF THE CT DATA.

             NOTE THAT ERREX DOES NOT ATTEMPT TO DETERMINE WHETHER
             AN UPDATE SHOULD BE CALCULATED. IF NO UPDATE IS PRESENT
             WITH WHICH TO CORRECT THE SYSTEM, THE ERROR STATE VECTOR
             IS INPUT AS ZERO AND THE CALCULATED CORRECTION IS ZERO.

\end{verbatim}
\end{frame}
