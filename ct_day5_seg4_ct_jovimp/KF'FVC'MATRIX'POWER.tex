KF'FVC'MATRIX'POWER
\begin{verbatim}
     FUNCTION:
             THIS FUNCTION CALCUALTES INTEGRAL POWERS (N)
             OF A "FOUR BY FOUR" MATRIX WHERE N > = 2. IT
             RETURNS THE "POWER MATRIX" IN THE CALLER'S
             "BASE MATRIX" DATA STRUCTURE.

\end{verbatim}
