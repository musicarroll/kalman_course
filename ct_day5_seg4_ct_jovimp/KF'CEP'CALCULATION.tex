\begin{frame}
KF'CEP'CALCULATION
\begin{verbatim}
     FUNCTION:

          THIS ROUTINE COMPUTES THE CIRCULAR ERROR PROBABILTY (CEP).
          CEP IS THE RADIUS OF A CIRCLE SUCH THAT THE POSITION HAS A
          PROBABILITY OF 0.5 OF BEING WITHIN THE CIRCLE. THE CIRCULAR
          ERROR PROBABILITY IS GIVEN BY:

              CEP = SIGMA MAX (0.674 + SIGMA MIN / SIGMA MAX (
                    0.0786 + 0.2573 ( SIGMA MIN / SIGNS MAX ) +
                    1.1108 ( SIGMA MIN / SIGMAM MAX ) )

          FOR SIGMA MIN / SIGMA MAX < 0.35

          AND

              CEP = SIGMA MAX ( 0.563 + 0.614 ( SIGMA MIN / SIGMA MAX))

          FOR SIGMA MIN / SIGMA MAX > 0.35

          WHERE SIGMA MAX AND SIGMA MIN REPRESENT THE MAGNITUDE OF
          MINIMIN PRINCIPLE VARIANCE AXES, RESPECTIVELY.

\end{verbatim}
\end{frame}
