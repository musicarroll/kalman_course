\begin{frame}
KF'TRANS'MATRIX'CALCULATION
\begin{verbatim}
     FUNCTION:
             THIS FUNCTION FUNCTION COMPUTES THE TRANSITION MATRIX
             ELEMENTS REQUIRED TO PROPAGATE THE COVARIANCE MATRIX AND
             ERROR STATE VECTOR FORWARD IN TIME. ADVANTAGE IS TAKEN OF THE
             PARTITIONING OF THE ERROR STATE VECTOR INTO TIME-VARYING
             AND NON-TIME-VARYING ELEMENTS BY WRITING THE TRANSITION
             MATRIX F AS FOLLOWS;

                           ]   FVV     FVN   ]
                       F = ]                 ]
                           ]   0        I    ]

             ONLY FVV AND FVN NEDD TO BE CALCULATED. THE 0 AND I
             SUBMATRICES ARE IMPLICITLY ASSUMED IN THE CALCULATION
             REQUIRING F.

             THE TRANS FUNCTION IS CALLED ONCE PER KALMAN CYCLE BY THE
             KALMAN CYCLE EXECUTIVE AND ALSO BY THE ERREX ROUTINE.

             THE TRANSITION MATRIX IS SUCH THAT

                  EX(T') = F(T',T) EX(T)

             TRANS APPROXIMATE F AS

             F(T',T) = I + A(T) (T'-T) + A(T) (T'-T)**2/2 + A(T)**2 (T'-T)**2/2

             THE OUTPUT OF TRANS IS AN ARRAY OF THE NON ZERO ELEMENTS OF THE
             TRANSITION MATRIX AND TWO ARRAYS ONE CONTANING THE ROW INDICES
             AND THE OTHER THE COL INDICES OF THE NON ZERO ELEMENTS AND THE
             NUBVER OF NON ZERO ELEMENTS

\end{verbatim}
\end{frame}
