\begin{frame}
OP'GPS'DATA'FETCH
\begin{verbatim}
FUNCTION:  This module selects the first set of GPS data 
           whose time tag falls in the interval of stored INS blocks.  
           If no set of GPS data falls in this INS interval, 
           no GPS observation will be selected in that 20-second interval.  
           GPS POS data can be picked up without GPS VEL data.   
           GPS VEL data will only be picked up 
           if there was a valid G13 message from the GPS.  
\end{verbatim}
\end{frame}
