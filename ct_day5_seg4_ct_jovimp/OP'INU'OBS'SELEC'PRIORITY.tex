\begin{frame}
OP'INU'OBS'SELEC'PRIORITY
\begin{verbatim}
     FUNCTION: The OPINUPRY subfunction shall select the observation to
     be processed during the next Kalman cycle for an INU in aided
     navigation based a system nav mode & availability of the various
     aids this Kalman cycle.  OPINPRY shall, if possible, choose each of
     the "continous" aids in order of priority, one each Kalman cycle.
     If the current observation is unavailable, move on to the next
     entry.

\end{verbatim}
\end{frame}
