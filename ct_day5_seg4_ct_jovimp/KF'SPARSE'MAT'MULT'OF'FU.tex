\begin{frame}
KF'SPARSE'MAT'MULT'OF'FU
\begin{verbatim}
     FUNCTION:
          THIS ROUTINE PERFORMS MATRIX MULTIPLICATION OF
          THE TRANSITION MATRIX  AND THE COVARIANCE MATRIX.
          UTILIZING THE SPARSE MATURE OF THE TRANSITION MATRIX.
          THE TRANSITION MATRIX IS STORED IN THE INPUT ARRAY
          "FU'FEL" AND THE INDICES OF THE NON-ZERO VALUES
          IN THE INPUT ARRAYS "FU'IROW" AND "FU'JCOL".

          THE COVARIANCE MATRIX IS STORED AS THE ELEMENTS
          OF THE VECTOR "FU'UK". THE ROUTINE PERFORMS THE
          MULTIPLICATION BY CYCLING THROUGH THE NON-ZERO
          ELEMENTS OF THE TRANSITION MATRIX AND DETERMINING
          WHICH ELEMENTS OF THE MATRIX CONTRIBUTE TO THE
          PRODUCT. IN ESSENCE, A GIVEN NON-ZERO ELEMENT
          OF THE TRANSITION MATRIX CONTRIBUTES ONLY TO THE
          TO THE ITH ROW OF THE PRODUCT. FURTHER, THE
          CONTRIBUTION TO THE KTH COLUMN (OF THE ITH ROW)
          IS F(I,J) * U(J,K) WHERE F IS THE TRANSITION
          MATRIX AND U IS THE COVARIANCE MATRIX.
          ALSO U(J,J) = 1 AND U(J,K) = 0 FOR K<J. THESE
          TWO FACTS ARE USED TO FUTHER REDUCE THE NUMBER
          OF OPERATIONS.

\end{verbatim}
\end{frame}
