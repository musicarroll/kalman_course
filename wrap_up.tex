\begin{itemize}
  \onslide<2->{
\item What have we learned?  
}
  \onslide<3->{
\item Kalman Filtering is really a kind of recursive averaging;  recursive, weighted least squares, in fact  
}
  \onslide<4->{
\item Full-blown Kalman filtering is mathematically rich, employing concepts from caclulus, linear algebra, statistics, optimization  
}
  \onslide<5->{
\item  Kalman Filtering is all about estimating the dynamic state of a system using all the 
information (or uncertainties) at our disposal
}
\end{itemize}
\end{frame}
\begin{frame}
  \onslide<1->{
	\frametitle{Kalman Filter Class 2018} 
	\framesubtitle{Wrap-up}
}
\begin{itemize}
  \onslide<2->{
\item  Kalman Filters only work optimally when certain assumptions are met
}
  \onslide<3->{
\item  But there are workarounds for situations where the assumptions are violated
}
  \onslide<4->{
\item  Going beyond these assumptions is subject of much current research:  Particle Filters, Unscented Kalman Filters,
$H_{\infty}$ Filters, higher order filters, machine learning techniques based on recurrent neural networks, general Bayesian filters, 
ensemble Kalman Filters (used in weather forecasting), smoothers, ...
}
\end{itemize}

\end{frame}
