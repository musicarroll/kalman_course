\begin{frame}
Transistion Matrix as Matrix Exponential
\begin{itemize}
  \item If system dynamics matrix $F$ is constant, i.e., not time-varying over the interval of interest, then $\Phi(\Delta t)$ can be expressed as matrix exponential:
\[\Phi(\Delta t) = I + F\Delta t + \dfrac{1}{2!}\left[F\Delta t\right]^2 + \dfrac{1}{3!}\left[F\Delta t\right]^3+\cdots\]
  \item If $\Delta t$ is small enough, the approximation $\Phi(\Delta t)\approx I+F\Delta t$ may be adequate
\end{itemize} 
\end{frame}
